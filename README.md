# Generalized Fourier Series

MATLAB implementation of the Generalized Fourier Series (GFS) method for aperiodic functions, as described by N. R. Rapaka and M. K. Riahi (2026).

The main file is [`IBVP.m`](IBVP.m).

## Citation

If you use this implementation in your research, please cite:

N. R. Rapaka & M. K. Riahi (2026). **Generalized Fourier Series: An *N log₂(N)* extension for aperiodic functions that eliminates Gibbs oscillations**. [*Mathematics and Computers in Simulation*](https://www.sciencedirect.com/journal/mathematics-and-computers-in-simulation), **249**, 208–228.
